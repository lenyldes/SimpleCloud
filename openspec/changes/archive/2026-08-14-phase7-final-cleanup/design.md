## Context

Три несвязанных между собой задачи технического долга закрываются одним изменением. Ограничения: TDD-роли (`[TEST-AGENT]` RED → `[CODE-AGENT]` GREEN), порог покрытия `internal/*` ≥85% (CI с Postgres-сервисом), локальные интеграционные DB-тесты скипаются без доступного Postgres (см. `IDEAS.md`), фронтенд — статический nginx без сборщика. Мотивация — в proposal.md.

## Goals / Non-Goals

**Goals:**
- Ветки ошибок `RunMigrations` (ReadDir/ReadFile fail, skip поддиректорий) покрываются unit-тестами без живой БД через синтетический файловый источник.
- `Content-Disposition` корректен для UTF-8 имён во всех современных браузерах и безопасен против заголовочных инъекций.
- Фронтенд не делает внешних запросов за шрифтами; CSP не меняется.

**Non-Goals:**
- Переезд миграций на сторонний инструмент (golang-migrate и т.п.).
- Изменение CSP-директив, включая удаление `'unsafe-inline'` из `style-src` (потенциальный бэклог).
- Шрифт JetBrains Mono и другие гарнитуры — остаются на системных фолбэках.
- Перенос DSN интеграционных тестов в env (O1/идеи из `IDEAS.md`) — отдельный бэклог.

## Decisions

**D1. Инъекция `fs.FS` вместо пакетного embed в миграциях.**
Сигнатура: `RunMigrationsFS(ctx context.Context, pool *pgxpool.Pool, fsys fs.FS) error`; существующая `RunMigrations` становится обёрткой `return RunMigrationsFS(ctx, pool, migrationFS)`. Чтение: `fs.ReadDir(fsys, "migrations")`, `fs.ReadFile(fsys, "migrations/"+version)`.
Альтернатива: собственный интерфейс-абстракция — отклонена, `io/fs.FS` стандартен и совместим с `embed.FS` и `fstest.MapFS` без адаптеров. Поведение прода не меняется — чистый рефакторинг для тестируемости.

**D2. Стратегия покрытия `internal/database` до ≥85%.**
Unit-тесты на `fstest.MapFS` покрывают FS-ветки без БД: отсутствие каталога `migrations`, пустой каталог, skip поддиректорий. Ограничение: `MapFS` не умеет симулировать ошибку `Open` у существующего файла, поэтому ветка `ReadFile`-ошибки тестируется кастомной `fs.FS`-обёрткой с падающим `Open` в тестовом коде. Интеграционные тесты с живой БД (скип без Postgres) покрывают ветки журнала/rollback: невалидный SQL → rollback, повторный запуск → skip применённых. Итоговое покрытие меряется в CI, где Postgres доступен.

**D3. Self-host Inter: один variable woff2 (latin subset).**
Файл кладётся в `services/web-frontend/src/assets/fonts/inter.woff2`; в CSS добавляется `@font-face { font-family: 'Inter'; src: url('/assets/fonts/inter.woff2') format('woff2-variations'); font-weight: 400 700; font-display: swap; }`. Variable-шрифт одним файлом закрывает все используемые веса (400/500/600/700), `font-display: swap` сохраняет поведение Google Fonts. Удаляются три `<link>` (`src/index.html:7-9`). Источник файла: официальный репозиторий rsms/inter или Google Fonts (woff2); файл коммитится в репо (~100-350 КБ, приемлемо для self-hosted). Альтернатива «удалить шрифт» отклонена пользователем в пользу сохранения дизайна.

**D4. Формат `Content-Disposition` и санация.**
В `DownloadHandler` (вместо `file.go:300`): хелпер строит заголовок:
- `filename*`: `UTF-8''` + percent-encoded имя (Go `url.PathEscape`).
- `filename`: ASCII-фолбэк — из имени удаляются не-ASCII байты; если результат пуст, используется `file`.
- Санация обоих значений: удаление/замена `\r`, `\n`, `"` до форматирования (защита от header injection; имя приходит из БД, но защита в глубину обязательна).
Альтернатива `mime.FormatMediaType` рассматривается как реализационная опция в GREEN-фазе (он сам кодирует RFC 5987 для не-ASCII `filename`); тесты фиксируют наблюдаемый формат заголовка, а не способ сборки.

## Risks / Trade-offs

- [Variable woff2 не поддержится очень старыми браузерами] → системные фолбэки в `--font-family-base` сохраняются; визуальный деград-путь безопасен.
- [Бинарный файл шрифта в git-репо увеличивает размер] → один файл ≤350 КБ; приемлемо, LFS не требуется.
- [Локальный прогон не покажет итоговое покрытие `internal/database` без Postgres] → порог проверяется в CI; локально тесты скипаются штатно.
- [`MapFS` не умеет симулировать ошибку `Open` у существующего файла] → ветка `ReadFile`-ошибки покрывается интеграционно/обходится тестом отсутствия каталога; при недоборе до 85% `[TEST-AGENT]` добавляет точечные тесты по отчёту coverage.
- [`%q`-форматирование текущего кода заменяется] → регрессия ловится тестом на ASCII-имя (поведение `report.pdf` не меняется по смыслу).

## Migration Plan

Обычный деплой через CI/CD: push в main → lint/tests/coverage → SSH-деплой на `pi5server`. Откат — revert коммита; миграций БД и изменений схемы нет. После архивации: `✅ L5` в `BUGS.md`, чекбоксы Technical Debt в `ROADMAP.md`, перенос O2 в архив `IDEAS.md`.
